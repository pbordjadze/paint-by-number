# Sources for The Pets We Actually Made

This ledger covers every quotation and numerical claim in [the chapter](chapter.md), plus the records behind the pet descriptions, failures and interpretation. Repository links are relative to this directory. Run evidence lives outside the repository under `/root/factory-out/F36/lamp` and `/root/factory-out/F40`; those links require the retained run artifacts. Existing folder and record keys are preserved in paths; the prose uses the guardians’ current first names.
