# Renumbering: the Lamp's answer

All nineteen seats agreed; none objected (`replies/`). Done on October 11, 2026: the seven docs
were renamed and each carries one italic line under its title saying it was renumbered, from
what, and how to read the old numbers inside it. No other words changed: the chapters cite each
other by their old numbers (chapter 1, formerly 3, does so 27 times), and the brief promised the
guardians that only the note would change.
