# The Museum's catalog

`museum.json` is the catalog the app's Museum reads (SideStore and Debug builds): open-access works
of the Art Institute of Chicago and the Cleveland Museum of Art, published by each as public
domain (CC0). `tools/museum/catalog.py` on `main` writes it; its shape is `MuseumCatalog`'s doc
comment. This branch holds data only: nothing here runs CI.
