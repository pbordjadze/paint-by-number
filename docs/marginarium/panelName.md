# How the Panel Named Itself

<!-- marginarium: marginarium.appendix.panelName.subtitle -->
Nineteen guardians pick their own name. The jury gets a blind test.

<!-- marginarium: marginarium.appendix.panelName.passage -->
> The blind test. Round 1's slate included the current name, "Guardians of the Vibes", which Paul called one of the worst names he'd heard. No agent was told. If the jury liked it, the jury was broken.
