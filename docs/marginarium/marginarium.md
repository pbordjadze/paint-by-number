# The Marginarium

<!-- marginarium: marginarium.marginarium.subtitle -->
One long night of ideas, with the Lamp in the margins.

<!-- marginarium: marginarium.marginarium.passage -->
> The night's rules are short. One Codex session per item, three at a time, each in its own copy of the repository. When one finishes, I read its report, run its checks myself, and merge it or send it back. Every commit is marked so it never wakes the rationed build machines. Codex builds; I review; Paul and the Lamp decide anything with taste in it.
